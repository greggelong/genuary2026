# **Physical Quine (Arduino + Servo + Piezo)**

## **Obeying orders becomes equivalent to giving orders**

## **服从命令等同于发出命令**

---

_Physical Quine_ is a small physical system that translates the computational idea of a quine into material form. In software, a quine is a program that outputs its own source code. This project asks what self-reference looks like when code is replaced by physical action, vibration, and mechanical repetition.

《物理 Quine》是一个将计算机中 Quine 概念转化为物理形式的系统。在软件中，Quine 指能够输出自身源代码的程序。本项目探讨当代码被物理动作、震动与机械重复所取代时，自我指涉会呈现出怎样的形态。

---

The work begins with a human gesture. A person taps a rhythm. The system listens, counts, and then reproduces the same pattern using a servo motor. These mechanical taps can be sensed again, becoming the next input. Output and instruction collapse into a single loop.

作品由人的动作启动。观众敲击一个节奏，系统进行感知与计数，并通过舵机重现该节奏。这些机械敲击可以再次被感知，成为新的输入，使输出与指令合并为一个循环。

---

The system is built around a thin piezo disk used as a vibration sensor, an Arduino microcontroller, and a small servo motor. The Arduino continuously listens for taps until a pause is detected, then triggers the servo to repeat the same number of taps. Non-blocking code allows listening and movement to occur simultaneously.

系统由薄型压电片（作为震动传感器）、Arduino 微控制器和小型舵机构成。Arduino 持续监听敲击信号，在检测到停顿后，驱动舵机重复相同次数的敲击。非阻塞代码结构使感知与运动能够同时发生。

---

The machine does not store commands or representations. Instruction emerges only through execution. The system listens to its own output and treats it as the next instruction, forming a recursive physical process rather than a symbolic one.

机器不存储指令或表征。指令仅在执行过程中生成。系统倾听自身的输出，并将其视为下一次指令，形成一种物理性的递归过程，而非符号运算。

---

Within this feedback loop, **obeying orders becomes equivalent to giving orders**. The system produces authority through repetition rather than decision. Compliance generates command. Hierarchy dissolves into a continuous cycle of execution.

在这一反馈循环中，**服从命令等同于发出命令**。系统通过重复而非决策来生产权威。服从本身生成指令，层级结构在持续执行中消解。

---

Rather than a machine that follows rules, _Physical Quine_ is a machine that manufactures rules by following them. It reframes obedience as a generative act and questions how systems sustain control when instruction and action are indistinguishable.

《物理 Quine》并非一台单纯遵循规则的机器，而是一套通过遵循规则来制造规则的系统。它将服从重新理解为一种生成性行为，并质疑当指令与行动无法区分时，系统如何维持控制。

---

The system is intentionally fragile. Mechanical vibration, loose wiring, power instability, or environmental noise can interrupt the loop. These breakdowns are not errors but integral to the work, exposing the physical limits of self-reference outside software.

系统被刻意设计为脆弱的。机械震动、松动的连接、电源不稳定或环境噪声都可能中断循环。这些中断并非错误，而是作品的一部分，揭示了自指在脱离软件环境后的物理极限。

---

For a residency or exhibition context, _Physical Quine_ can expand into a distributed installation of 15–20 small units. Each unit operates independently while responding to shared environmental conditions such as human movement, vibration, and ambient sound.

在驻留或展览语境中，《物理 Quine》可扩展为由 15 至 20 个小型单元组成的分布式装置。每个单元独立运行，同时对人的移动、震动及环境声音等共享条件作出回应。

---

The units influence one another indirectly through the environment. A passing body or a sudden sound may trigger multiple systems at once, producing emergent collective rhythms without centralized control.

这些单元通过共享的环境间接相互影响。行走的人体或突发的声音可能同时触发多个系统，在没有中心控制的情况下生成集体性的节奏。

---

The installation allows for flexible scale and organization, from dense grids to loose clusters. Each configuration explores different relationships between order and noise, autonomy and synchronization.

装置在规模与组织方式上具有灵活性，可从密集网格到松散聚集体不等。每种配置都探索秩序与噪声、自主性与同步性之间的不同关系。

---

_Physical Quine_ translates recursion from code into matter. By allowing a machine to listen to and repeat its own actions, the project examines labor, obedience, and self-reference as physical processes shaped by instability, repetition, and environment.

《物理 Quine》将递归从代码转化为物质。通过让机器倾听并重复自身的行动，作品将劳动、服从与自指理解为受不稳定性、重复和环境影响的物理过程。
